TrackLogic 是面向模拟赛车玩家的桌面工具。它连接 iRacing，自动记录驾驶过程中的遥测数据，帮助你从圈速、刹车、油门、方向、轮胎、赛道位置和比赛表现中找到真正的时间损失，并把分析结果转化为下一圈可以执行的改进。

目前 TrackLogic 以 **iRacing** 为主要支持对象。软件、最新版本和安装包请以 [apexracing.cn 官方网站](https://apexracing.cn/) 为准。

## 为什么使用 TrackLogic

只看最终圈速，通常只能知道“慢了多少”，却很难知道“为什么慢”。TrackLogic 把驾驶记录、遥测曲线、圈速对比、赛道地图和实时驾驶辅助放在同一个工作流里：

1. 启动 TrackLogic 与 iRacing。
2. 正常练习、排位或比赛，软件在后台记录遥测。
3. 驾驶结束后查看圈速、分段和遥测数据。
4. 对比自己的不同圈，或选择社区中的参考圈。
5. 根据差距调整刹车点、入弯速度、线路和油门释放方式。

## 主要功能

### 遥测记录与个人车库

- 自动记录驾驶会话和有效圈速。
- 按赛季、赛道、车型和时间查找自己的记录。
- 保存圈速、分段、赛段、油量和轮胎等数据。
- 将驾驶记录集中保存在个人车库，方便长期追踪进步。

### 圈速与遥测分析

- 查看最快圈、平均圈速、分段成绩和圈数。
- 对比最多 4 圈，定位每个赛道区段的时间差。
- 查看速度、油门、刹车、方向盘输入等遥测曲线。
- 分析轮胎温度、胎压、磨损、油量消耗和进站信息。
- 支持按时间或赛道距离查看差异，帮助判断时间损失发生在哪里。

### 赛道地图与驾驶表现

- 在赛道地图上查看驾驶线路和车辆位置。
- 结合圈速、分段和赛道位置理解每个弯道的表现。
- 通过个人记录和社区数据建立更有参考价值的基准圈。

### 实时信息叠加与驾驶辅助

TrackLogic 可以将实时信息显示在游戏画面上，减少驾驶过程中切换窗口的需要。可用模块包括：

- 操作输入：油门、刹车、离合器、方向盘和挡位。
- 全场排名与相对排名。
- 赛道地图和车辆位置。
- 声音提醒。
- 盲点监测，提示左右两侧相邻车辆。
- 参考圈对比和速度差。
- 基于参考圈刹车点的视觉与声音刹车提醒。
- 灵动岛式信息面板，以及可预览、编辑和缩放的布局。

### 赛车学院与训练

赛车学院用于把遥测分析转化为可重复的训练过程。你可以围绕参考圈、刹车点、速度差和驾驶输入进行专项练习，并逐步建立自己的训练记录。

### 社区与性能数据

- 浏览社区圈速和参考数据。
- 使用社区圈速辅助个人圈速对比。
- 查看自己的驾驶进步与赛道表现。
- 记录游戏流畅度、帧率、延迟和通信质量，帮助排查联机与性能问题。

## 快速开始

1. 打开 [apexracing.cn](https://apexracing.cn/)，下载并安装 TrackLogic。
2. 启动 TrackLogic，并按提示登录或创建账号。
3. 启动 iRacing，进入练习、排位或比赛。
4. 确认 iRacing 已开启遥测保存功能；TrackLogic 会在后台等待并采集可用数据。
5. 完成驾驶后，在“我的遥测”或“我的车库”中查看记录。
6. 选择两圈或多圈进行对比，再根据分析结果调整下一次驾驶。

## 使用建议

- 第一次使用时，建议先完成一个完整会话，再开始分析。
- 想比较驾驶差异时，尽量选择同一赛道、同一车型和相近条件下的有效圈。
- 使用实时信息叠加前，先在设置中打开预览并调整位置、大小和显示模块。
- 如果没有生成遥测记录，请先完全退出 iRacing，再检查遥测保存设置和磁盘空间。
- 网络异常时先检查连接状态；本地已有的驾驶数据和客户端状态可能需要稍后同步。

## 常见问题

### TrackLogic 支持哪些模拟赛车？

当前版本以 iRacing 为主要支持对象。其他模拟赛车是否支持，请以 [官网兼容性说明](https://apexracing.cn/) 和软件内提示为准。

### 安装后没有看到遥测记录怎么办？

请确认 iRacing 已经完全启动并进入驾驶会话，且已允许将遥测保存到磁盘。完成驾驶后等待软件处理数据；如果仍然没有记录，请在应用内重试，并检查网络与磁盘空间。

### 这是开源软件吗？

本仓库用于发布 TrackLogic 的用户文档，不代表客户端源代码完全开放。客户端安装包、版本说明和产品信息以官方主页为准。

### 在哪里获取更新和帮助？

请访问 [apexracing.cn](https://apexracing.cn/) 获取最新版本、更新说明和官方支持入口。
